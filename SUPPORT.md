# Support

WavWiz is a **public beta**. Best-effort help from the community and maintainers; there is no paid support SLA.

## Where to get help

| Channel | Use for |
| --- | --- |
| [GitHub Issues](https://github.com/vdubbin74/WavWiz/issues) | Bugs and concrete feature requests |
| [GitHub Discussions](https://github.com/vdubbin74/WavWiz/discussions) | Questions and how-to (if Discussions are enabled on the repo) |
| [wavwiz.com](https://wavwiz.com) | Product overview and FAQ |
| [SECURITY.md](SECURITY.md) | Vulnerabilities only (private email — **not** public Issues) |

## Before you open an issue

1. Confirm you installed from the official [Releases](https://github.com/vdubbin74/WavWiz/releases) page.
2. Try the latest beta.
3. Skim [docs/FIRST-RUN.md](docs/FIRST-RUN.md) (Private network, admin password, music folders, AirPlay, optional Spotify Connect).
4. Search existing Issues for duplicates.

## What to include in a bug report

- **WavWiz version** (Help → About, or installer name such as `WavWiz-Setup-<version>.exe`)
- **Windows version** (and whether the problem is on Server PC, Player PC, or phone browser)
- **What you expected** vs **what happened**
- **Steps to reproduce**
- A copy of **Diagnostics** from the app (Settings / Diagnostics — paste text; redact personal folder paths if you prefer)
- Whether AirPlay or Spotify Connect was involved
- Screenshots or short clips when UI-related

Feature requests: describe the problem you are solving, not only a preferred UI sketch.

## What we cannot help with here

- Spotify account billing or password recovery (contact Spotify)
- Apple ID / AirPlay on non-Apple senders beyond “does WavWiz appear on the LAN?”
- General Windows networking unrelated to WavWiz
