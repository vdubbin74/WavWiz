FFmpeg in WavWiz - build information and source offer
=====================================================

WavWiz uses FFmpeg to decode your music files and radio streams, to make small cover-art thumbnails, and to encode ripped CD audio (FLAC, AAC, and MP3 via LAME). It runs it as a separate program
(Server\ffmpeg\ffmpeg.exe) with these shared libraries next to it: avcodec-62.dll, avformat-62.dll, avutil-60.dll, avfilter-11.dll, swresample-6.dll, swscale-9.dll.

LICENSE: GNU Lesser General Public License, version 2.1 or later (the LGPL build of FFmpeg).
  - Built WITHOUT --enable-gpl, WITHOUT --enable-nonfree, and WITHOUT --enable-version3. No GPL or non-free libraries (no x264, x265, fdk-aac).
  - Encoders: JPEG (cover thumbnails), raw PCM, FLAC, native AAC, and libmp3lame (LAME 3.100, LGPL). LAME is a separately replaceable shared DLL next to FFmpeg.
  - No GPL code is included. --enable-libmp3lame does not require --enable-gpl.
  - The libraries are shared DLLs: you can replace them with your own build of the same FFmpeg (ABI: avcodec 62, avformat 62, avutil 60, avfilter 11, swresample 6, swscale 9)
    or point "ffmpegPath" in C:\ProgramData\WavWiz\server.json at any other ffmpeg.exe. The unmodified source and the build script are included (see below).
  - zlib 1.3.1 (zlib license) is linked into the FFmpeg libraries; the Windows system TLS library (Schannel) is used for https radio.
  - License texts: COPYING.LGPLv2.1.txt and COPYING.LGPLv3.txt in this folder. FFmpeg is a trademark of Fabrice Bellard; WavWiz is not endorsed by or affiliated with the FFmpeg project.
