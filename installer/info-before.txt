WavWiz (BETA) - whole-home synchronized music (formerly Unison)

This is a BETA version. It is meant for you to try on your own home network. Things will change and some things are still missing.

What it does
  * Plays your own music files and internet radio on several PCs at once, in sync, across your home.
  * WavWiz Player shows the controls in its own window on each PC; phones and tablets use the same controls in a web browser.
  * You can group speakers into zones, set volume and on/off per device, and tune each speaker's delay (a phone microphone makes this automatic).
  * On first run you choose an administrator password (in WavWiz Player or the web page on the server PC).

What it never does
  * It does not send anything to the internet, has no accounts, no analytics and no telemetry.
  * It listens only on the home-network address you choose (never "all interfaces"), only answers devices on your own network, and every control needs a password or a paired device.
  * It does not change any antivirus, Windows security or network-profile setting.

What gets installed
  * WavWiz Server (a Windows service, "WavWiz Server (BETA)") - on the PC that holds your music.
  * WavWiz Player - on every PC with speakers (can be the same PC).
  * A private-network-only Windows Firewall rule for the server. Windows should list your home network as Private.

This installer is not code-signed yet, so Windows SmartScreen may warn you. That is expected for a beta.
